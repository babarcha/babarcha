## About me

I am an embedded software engineer and PhD researcher with experience in **5G/LTE physical-layer software**, **microcontroller firmware**, **embedded Linux**, and **hardware/software verification**. I combine practical C/C++ and Python engineering with research in **Human-in-the-Loop AI**, cooperative intelligence, and assistive digital health.

- **Engineering:** Real-time firmware, UART / I²C / SPI / CAN interfaces, RTOS, modular design
- **Validation:** Python/pytest, Robot Framework, unit tests, CI, simulation and HIL concepts
- **Wireless:** 5G NR / LTE L1 PHY, signal processing, wireless connectivity
- **Research:** Intelligent edge systems, human–AI cooperation and assistive navigation
